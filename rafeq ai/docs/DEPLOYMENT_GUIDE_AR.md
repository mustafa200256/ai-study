## 1. كيفية تثبيت وتشغيل تطبيق Android (APK)

1. تم إنشاء ملف الـ APK النهائي القابل للتثبيت في المسار:
   `dist-apk/RafeeqStudentAI-debug.apk`
2. انقل الملف إلى هاتفك عبر كابل USB، أو عبر Telegram / Google Drive.
3. افتح الملف على الهاتف واضغط على **تثبيت (Install)**.
4. إذا ظهرت رسالة أمان: "تثبيت تطبيقات من مصادر غير معروفة"، اضغط على **الإعدادات** وفعّل السماح لهذا المصدر.
5. سيظهر التطبيق على الشاشة الرئيسية باسم: **رفيق الطالب العراقي AI**.
6. عند فتح التطبيق، ستجد جميع الأقسام: جدول المذاكرة، المناهج، بنك الأسئلة الوزارية، الملاحظات، المدرس الذكي، وصفحة حول المطور (مصطفى حسين).

---

## 2. لوحة الإدارة السحابية (Cloudflare Pages — مجانية 100%)

لوحة الإدارة مصممة كـ Single Page Application خفيفة ومستقلة تماماً، تعمل على المتصفح والهاتف دون الحاجة لخوادم معقدة.

### خطوات النشر على Cloudflare Pages:
1. أنشئ حساباً مجانياً على [Cloudflare](https://dash.cloudflare.com/).
2. انتقل إلى **Workers & Pages** &rarr; اضغط **Create application** &rarr; اختر تبويب **Pages**.
3. اختر **Upload assets** (رفع ملفات مباشرة).
4. حدد اسم المشروع: `rafeeq-admin`.
5. اسحب وأفلت المجلد `admin-dashboard` الموجود في المشروع.
6. اضغط **Deploy site**.
7. ستحصل فوراً على رابط مجاني دائم وسريع مع شهادة SSL مجانية، مثل:
   `https://rafeeq-admin.pages.dev`
8. يمكنك فتح الرابط من هاتفك أو حاسوبك وإدارة الطلاب وطلبات المحافظ والمحتوى فوراً!

## 3. قاعدة البيانات والمصادقة (Supabase — مجانية)

1. أنشئ حساباً مجانياً على [Supabase](https://supabase.com).
2. أنشئ مشروعاً جديداً باسم `rafeeq-student-ai` واختر كلمة مرور لقاعدة البيانات.
3. بعد اكتمال إنشاء المشروع، انتقل من القائمة الجانبية إلى **SQL Editor**.
4. افتح الملف الموجود في مشروعك:
   `backend/supabase/migrations/20261023_init_rafeeq.sql`
5. انسخ محتواه بالكامل والصقه في SQL Editor واضغط **Run**.
6. سيتم إنشاء جميع الجداول، الصلاحيات (Row Level Security)، والإجراءات المخزنة بأمان.

---

## 4. كيفية إنشاء حسابك كمدير رئيسي (Super Admin) بأمان تام

لحماية مشروعك، **لم يتم وضع أي كلمة مرور ثابتة داخل الكود**. إليك الطريقة الآمنة لإنشاء حسابك:

1. ادخل إلى لوحة Supabase &rarr; **Authentication** &rarr; **Users** &rarr; اضغط **Add User** &rarr; **Create User**.
2. اكتب بريدك الإلكتروني الشخصي الذي تريده، واختر كلمة مرور قوية خاصة بك.
3. بعد إنشاء الحساب، انتقل إلى **SQL Editor** في Supabase ونفّذ الأمر التالي (استبدل بريدك الفعلي):
   ```sql
   SELECT public.grant_super_admin('بريدك_هنا@gmail.com');
   ```
4. ستحصل على رسالة:
   `تم ترقية المستخدم إلى Super Admin بنجاح!`
5. الآن حسابك أصبح المدير العام الوحيد المخول بالموافقة على الدفع وتعديل إعدادات النظام!

## 5. تفعيل الذكاء الاصطناعي الحقيقي ومفتاح GROQ_API_KEY

تم تصميم المدرس الذكي ليعمل عبر مزود **Groq** المجاني والفائق السرعة بنموذج **LLaMA 3.3 70B Versatile**.

### أين وكيف تضع المفتاح؟
1. ادخل مجاناً إلى [Groq Console](https://console.groq.com/keys).
2. سجل دخولك واضغط **Create API Key**.
3. انسخ المفتاح الذي يبدأ بـ `gsk_...`.
4. **إذا كنت تستخدم خادم Node.js المحلي / السحابي:**
   - افتح المجلد `backend/server`.
   - أنشئ ملفاً باسم `.env` (أو عدل `.env.example`).
   - اكتب بداخله:
     ```env
     PORT=3000
     GROQ_API_KEY=gsk_ضع_مفتاحك_هنا
     AI_MODEL=llama-3.3-70b-versatile
     ```
   - شغّل الخادم عبر الأمر:
     ```bash
     cd backend/server
     npm install
     npm start
     ```
5. **إذا كنت تستخدم Supabase Edge Functions:**
   - انتقل إلى لوحة Supabase &rarr; **Edge Functions** &rarr; **Secrets**.
   - أضف مفتاحاً جديداً باسم `GROQ_API_KEY` وقيمته المفتاح المنسوخ.
6. التطبيق سيتصل مباشرة بالمدرس الذكي ويشرح المسائل للطلاب مع حماية كاملة للمفتاح.

## 6. دورة قبول وتأكيد طلبات دفع المحافظ (SuperQi / زين كاش / FIB)

1. يقوم الطالب باختيار الخطة والتحويل إلى رقم محفظتك الظاهر في التطبيق.
2. يرسل الطالب رقم المعاملة وهاتفه عبر التطبيق.
3. يظهر الطلب فوراً في لوحة الإدارة في قسم **«طلبات الدفع والمحافظ»** بحالة `بانتظار التحقق`.
4. تفتح تطبيق محفظتك (SuperQi أو زين كاش) وتتأكد من استلام المبلغ الفعلي ومطابقة رقم الإشعار.
5. تضغط على زر **«تأكيد وتفعيل»** في لوحة الإدارة.
6. يتحقق الخادم من صلاحيتك كمدير، ويتم تفعيل الخطة الذهبية للطالب فورياً ويسجل القرار في سجل العمليات الإدارية (Audit Log).
