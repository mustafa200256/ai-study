خيارات النموذج والخادم

أين تضع المفتاح السري بأمان؟

لضمان الأمان الأقصى، لا يتم إدخال مفتاح API في واجهة المتصفح أو تطبيق الهاتف.

إذا كنت تستخدم Supabase:

ادخل إلى لوحة Supabase → Edge Functions → Secrets وأضف المتغير:

GROQ_API_KEY = gsk_...
إذا كنت تستخدم Node.js Server:

افتح ملف backend/server/.env وضع المفتاح داخل السطر:

GROQ_API_KEY=gsk_...
