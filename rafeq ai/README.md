## 🌟 نظرة عامة على المشروع

**«رفيق الطالب العراقي AI»** هو منظومة برمجية متكاملة مصممة خصيصاً لتلبية احتياجات الطالب العراقي (خاصة مرحلة السادس الإعدادي العلمي والأدبي، والثالث المتوسط). يجمع التطبيق بين:
1. **تطبيق Android أصلي (Native Kotlin & Jetpack Compose)** بتصميم كحلي وذهبي ملكي أنيق مع دعم كامل للغة العربية واتجاه RTL.
2. **مدرس ذكي (AI Tutor)** مدرب على نمط أسئلة المنهج العراقي ويشرح القوانين والمسائل خطوة بخطوة بالاستفادة من نماذج الذكاء الاصطناعي (Groq LLaMA 3.3 70B).
3. **لوحة تحكم إدارية سحابية (Web Admin Dashboard)** باللغة العربية بالكامل، تتيح للمبرمج **مصطفى حسين** إدارة المشتركين، مراجعة وتأكيد طلبات دفع المحافظ الإلكترونية، تعديل الأسئلة والمناهج فورياً دون الحاجة لبناء APK جديد، ومراقبة استهلاك الذكاء الاصطناعي.
4. **خادم وسيط آمن (Backend / Supabase Edge Functions)** لحماية مفاتيح API السرية (`GROQ_API_KEY`) ومنع كشفها في التطبيق أو ملفات APK نهائياً.

## 📱 أقسام ومميزات تطبيق Android

* **الرئيسية (Dashboard):** رسالة ترحيبية باسم الطالب، نسبة إنجاز المهام اليومية، بطاقة الوصول السريع للمدرس الذكي، اختصارات الفصول، وتنبيهات المهام القادمة.
* **المدرس الذكي AI (AI Tutor):** واجهة محادثة ذكية باللغة العربية، تدعم اقتراحات الأسئلة الوزارية الشائعة (قاعدة لوشاتليه، مبرهنة رول، كم الاستفهامية، المتسعات، إلخ)، نسخ الشرح، مؤشر تفكير تفاعلي، وتوضيح صريح عند انقطاع الاتصال أو غياب مفتاح API.
* **المنهج العراقي (Curriculum):** استعراض شامل لمواد السادس الإعدادي (الرياضيات، الفيزياء، الكيمياء، الأحياء، اللغة العربية، الإنجليزية، الإسلامية) بفصولها وثقلها من الدرجات الوزارية.
* **جدول الدراسة الذكي (Study Schedule):** إضافة المواد، الدروس، تحديد الوقت والتاريخ والأولوية، وضع علامة الإكمال، التعديل والحذف، مع حفظ البيانات محلياً عبر **Room Database**.
* **الاختبارات التفاعلية (Interactive Quizzes):** أسئلة اختيار من متعدد بالمنهج العراقي، تصحيح فوري، احتساب النسب المئوية، توضيح الإجابات النموذجية، وسجل المحاولات السابقة.
* **الملاحظات والملخصات (Notes & Summaries):** كتابة وحفظ الملخصات، البحث السريع، التصنيف حسب المادة، والنسخ والمشاركة عبر تطبيقات الهاتف (Share Intent).
* **الإنجازات والتقدم (Achievements):** إحصائيات مبنية على دراسة الطالب الفعلية (المهام المكتملة، الاختبارات، الأوسمة والشارات التقديرية).
* **الاشتراك والمحفظة (Subscription & Wallet):** استعراض ميزات الباقة الذهبية، وطريقة الدفع عبر المحافظ العراقية (**SuperQi**، **زين كاش**، **FIB**) مع إرسال رقم المعاملة للتحقق اليدوي الآمن.
* **الإعدادات وحول التطبيق (Settings & About):** التبديل بين الوضع الليلي الكحلي والوضع الفاتح، تعديل بيانات الطالب، فحص وتعديل رابط خادم Backend، سياسة الخصوصية، وتكريم خاص للمطور **Mustafa Hussein — مصطفى حسين**.

## 💻 أقسام لوحة الإدارة (Web Admin Dashboard)

لوحة تحكم تفاعلية متجاوبة مع الهواتف والحواسيب الشخصية باللغة العربية:
1. **الرئيسية والمؤشرات:** إحصائيات الطلاب، الاشتراكات النشطة، طلبات الدفع المعلقة، وإجمالي دخل المحافظ.
2. **إدارة الطلاب:** البحث، تعديل الخطط (مجاني / ذهبي)، وحظر الحسابات المسيئة.
3. **طلبات الدفع:** تدقيق رقم الهاتف ورقم المعاملة ومطابقتها مع تطبيق المحفظة قبل الضغط على زر «تأكيد وتفعيل» أو الرفض مع ذكر السبب.
4. **إعدادات المحفظة والأسعار:** تغيير أرقام محفظة SuperQi وزين كاش وFIB وأسعار الباقات من المتصفح مباشرة.
5. **إعدادات الذكاء الاصطناعي:** تحديد المزود (Groq / OpenAI)، اختيار النموذج، وتحديد حد الأسئلة اليومي لكل طالب.
6. **إدارة المحتوى والأسئلة:** إضافة أسئلة وزارية جديدة وتعديل المناهج لتظهر في التطبيق فورياً دون تحديث ملف APK.
7. **إعدادات التطبيق:** تعديل الرسالة الترحيبية، الشريط الإخباري، وأرقام الدعم الفني.
8. **سجل العمليات (Audit Logs):** توثيق كل قرار دفع وتعديل صلاحيات مع هوية المدير ووقت العملية.
9. **حول النظام:** صفحة توثيق المنظومة وصاحب المشروع مصطفى حسين.

## 🚀 البدء السريع (0 دينار تكلفة استضافة)

### 1. تشغيل لوحة الإدارة
افتح ملف `admin-dashboard/index.html` في أي متصفح مباشرة، أو انشره مجاناً على **Cloudflare Pages** برفع المجلد بضغطة زر واحدة.

### 2. تشغيل خادم الذكاء الاصطناعي (Node.js)
```bash
cd backend/server
npm install
# أنشئ ملف .env وضع فيه مفتاحك المجاني من console.groq.com:
# GROQ_API_KEY=gsk_...
npm start
```

### 3. إنشاء حساب المدير العام (Super Admin) بأمان
- ادخل إلى Supabase وقم بإنشاء حسابك ببريدك الشخصي.
- في SQL Editor نفذ:
  ```sql
  SELECT public.grant_super_admin('بريدك_الشخصي@domain.com');
  ```
